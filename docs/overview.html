01

หาคนทำงานยาก — เจอคนที่ใช่ได้ยาก

คนว่างงานเยอะ แต่ไม่มีที่ที่ผู้ว่าจ้างจะหาคนที่ตรงกับงานและเชื่อถือได้ ข้อมูลกระจายอยู่ตามเฟซบุ๊กกลุ่มเก่า ๆ

02

ไม่รู้ว่าคนที่มาทำน่าเชื่อถือแค่ไหน

ไม่มีประวัติงาน ไม่มีรีวิวจากผู้ว่าจ้างคนก่อน ไม่มีหลักฐานว่าเคยทำงานนี้สำเร็จ

03

ตกลงงานนอกระบบ — เมื่อมีปัญหาไม่มีทางออก

ยืนยันงานกันเสร็จก็จบ ไม่มีการบันทึกราคาที่ตกลง ไม่มีการติดตามงาน ไม่มีช่องทางร้องเรียน

04

ผู้ให้บริการก็เสียเปรียบเช่นกัน

เสียเวลาไปหางานที่ไม่เหมาะกับทักษะ ไม่มีลูกค้าประจำ ไม่มีช่องทางสร้างชื่อเสียงระยะยาว

02ปัญหา
ภาพรวมระบบ

สามฝั่งที่ทำงานเข้าหากัน

ฝั่งที่เสนอบริการ

ผู้ให้บริการ

คนที่มีฝีมือ — ช่าง คนขับรถ คนรับจ้างทั่วไป

  • ลงประกาศงานที่ทำได้ พร้อมราคาและรูป
  • กำหนดเวลาที่ว่างและวันที่ไม่รับงาน
  • รับการจอง เลือกวันที่สะดวก
  • ยืนยันรับงานและราคาที่ตกลงกัน
  • สะสมชื่อเสียงและรีวิวจากผู้ว่าจ้าง
  • เหรียญตราและการยืนยันตัวตน
ฝั่งที่ต้องการคน

ผู้ว่าจ้าง

คนที่ต้องการจ้าง — เจ้าของร้าน หัวหน้างาน คนทั่วไป

  • ลงประกาศว่าต้องการใครทำอะไร
  • ค้นหาจากประเภทงาน ที่ตั้ง และคำค้น
  • ดูประวัติ รีวิว และคะแนนความน่าเชื่อถือก่อนตัดสินใจ
  • เลือกวันเวลาและฝั่งจอง
  • ติดตามการเดินทางของผู้ทำงานแบบเรียลไทม์
  • ยืนยันรับงานและปล่อยเงิน
ฝั่งดูแลความเรียบร้อย

ผู้ดูแลระบบ

ทีมงาน — คอยดูแลว่าตลาดยังน่าเชื่อถือ

  • ตรวจสอบประกาศที่ถูกรายงาน
  • ระงับประกาศที่ไม่เหมาะสม
  • อนุมัติการยืนยันตัวตนและเหรียญตรา
  • รับเรื่องร้องเรียนและช่วยตัดสิน
  • จัดการกระบวนการแต้มและรางวัล
  • ดูแลกระเป๋าเงินและรายการธุรกรรม

ฟีเจอร์ 04

เงิน รางวัล และการคุยกัน

กระเป๋าเงิน

ผู้ใช้มียอดเงินในระบบ ดูประวัติทุกรายการว่าเข้าออกจากอะไร ราคาที่ตกลงกันถูกบันทึกไว้ในประวัติงานเสมอ

◷ ยังไม่ได้ต่อช่องทางชำระเงินจริง

ระบบแต้มกิจกรรม

กำหนดกิจกรรมที่ให้แต้ม — เช่น เข้าใช้งานประจำวัน รีวิวงาน สร้างประกาศ ระบบแจ้งเตือนและจ่ายแต้มอัตโนมัติตามเวลาที่กำหนด

✓ ทำงานอัตโนมัติแล้ว

แชทในงาน

คุยกันในแชทของแต่ละงาน ทั้งแบบสมัครสมาชิก และแบบใช้เบอร์มือถือสำหรับลูกค้าที่ยังไม่ได้สมัคร

✓ มีสถานะการอ่านแล้ว

โครงสร้างกระเป๋าเงิน การชำระเงิน และการร้องเรียน เตรียมไว้ครบแล้ว — เหลือต่อเข้ากับผู้ให้บริการชำระเงินจริง และเปิดให้ผู้ใช้เปิดข้อร้องเรียนเองได้

สิ่งที่ต้องทำต่อ

รายการที่ต้องคุมไว้
ก่อนปล่อยให้ผู้ใช้จริง

เชื่อมระบบชำระเงินจริงโครงสร้างพร้อมแล้ว — ต้องต่อผู้ให้บริการและทดสอบการคืนเงิน
โครงสร้างพร้อม
ปิดช่องอัปโหลดไฟล์ และเพิ่มการตรวจสิทธิ์ตอนนี้บางจุดเปิดให้ทุกคนที่เข้าถึง — ต้องแก้ก่อนเปิดสาธารณะ
จำเป็น
เปิดให้ผู้ใช้ส่งข้อร้องเรียนเองได้ตอนนี้มีหน้าสำหรับผู้ดูแลเท่านั้น — ผู้ใช้ยังส่งเรื่องไม่ได้
จำเป็น
แจ้งเตือนผ่าน SMS และแอปปัจจุบันผู้ใช้ต้องเปิดหน้าเว็บเองถึงจะเห็น

เฟสที่ 1 · เริ่มทันที

ปิดช่องโหว่
และเปิดทางให้ทีมมือถือ

  • ปิดช่องอัปโหลด เพิ่มการตรวจสิทธิ์ให้ครบทุกจุด
  • แก้เส้นทางที่ทำให้ระบบผิดพลาด
  • ส่งเอกสาร API ให้ทีมพัฒนาแอป
  • เปิดให้ผู้ใช้ส่งข้อร้องเรียนเอง
เฟสที่ 2 · เติบโต

แอปมือถือ
และการชำระเงิน

  • ทีมภายนอกพัฒนาแอปจาก API ที่มีอยู่แล้ว 103 ช่องทาง
  • เชื่อมผู้ให้บริการชำระเงินจริง
  • เพิ่มการแจ้งเตือนผ่านแอปและ SMS
  • ระบบคูปองและใบเสร็จ
เฟสที่ 3 · ขยายตลาด

ทำให้ตลาด
เติบโตเอง

  • ประสิทธิภาพของระบบรีวิวและการค้นหา
  • แนะนำงานตามความน่าเชื่อถือและที่ตั้ง
  • ระบบสมาชิกและสิทธิพิเศษสำหรับผู้ใช้ประจำ
  • ขยายไปหมวดงานใหม่ ๆ นอกเหนืองานรถรับจ้าง

จุดตัดสิน: เฟสที่ 1 ปิดช่องโหว่ก่อนปล่อยให้คนใช้จริง — ส่วนแอปมือถือเริ่มทำได้ทันทีเพราะช่องทาง API พร้อมแล้วทั้งหมด
